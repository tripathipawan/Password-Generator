# Password Generator :-

Welcome to the Password Generator! This is a simple, responsive, and user-friendly web application designed to generate strong, secure passwords. The app allows you to create random passwords of lengths between 8 and 18 characters, utilizing uppercase letters, lowercase letters, numbers, and symbols. It’s perfect for anyone looking to generate secure passwords for online accounts or personal use.

# Features :-

1. Customizable Password Length: Generate passwords with lengths between 8 and 18 characters to suit your needs.
2. Password Strength: The password can include a mix of uppercase letters, lowercase letters, numbers, and symbols, making it secure and complex.
3. Responsive Design: The app adjusts automatically to different screen sizes, offering a smooth experience on desktop, tablet, and mobile devices.
4. User-Friendly Interface: Simple, intuitive controls that allow you to customize the generated password with ease.
5. Media Queries: The app uses media queries to ensure it looks great on all devices, adjusting the layout for optimal use.

# Technologies Used :-

1. HTML: Used for structuring the content of the app, including input fields, buttons, and the password display.
2. CSS: For styling the layout, ensuring a clean, modern, and responsive design.
3. JavaScript: Handles the logic behind generating random passwords, including character selection and length customization.
4. Media Queries: Ensures the app adapts to various screen sizes, providing a seamless experience on both small and large devices.
